# LAMDAG-Portable

Portable version of the LAMDAG (Lesson Plan Generator) application.

## How to Use

1. Extract the contents of this folder to your desired location
2. Open a command prompt/terminal in the LAMDAG-Portable folder
3. Run `run.bat` or execute `run.bat` from File Explorer
4. The application will start and automatically open in your default browser

## Features

- Complete lesson plan generator application
- SQLite database with curriculum data
- Web interface for creating lesson plans
- PDF and DOCX export capabilities
- All dependencies included in the portable version

## Requirements

- Windows 10 or higher (tested on Windows 11)
- Python 3.12 or higher (included in the portable version)
